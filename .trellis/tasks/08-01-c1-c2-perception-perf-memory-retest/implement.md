## 3. 回放隔离 sanitizer（ASan 构建，C1、C2 各一遍）

> 原则：sanitizer 是路径覆盖工具，不需要时长与循环；需要走全真实路径 +
> 干净退出（SIGTERM 让 LSan 清点，禁止 SIGKILL）。

- [x] **ASan+LSan 单圈**真实 bag 回放；跟不上 10 Hz 就 `--rate 0.5`。
- [x] **2 份拼接 bag 单圈**：覆盖位姿跳变 → fail-closed → epoch 重置/重建路径
      （拼 2 份是为路径覆盖，非趋势积累）。
- [x] **Memcheck 一遍**，`--rate 0.1` 起步；definite/possible loss 逐条归因
      业务 vs 基础设施（rcutils/glibc/LTTng 类）。
- [x] **阳性对照一次**：人造泄漏（如临时构建塞不释放的分配）跑通全流程，
      证明检测流程能抓住阳性 → **阻塞门**、闭合上轮"报告门未被反例验证"缺口。
- [x] 每次运行对第 2 步计数基准核对等价 → **阻塞门**、**AC4**。

## 4. 回放隔离泄漏长跑（普通构建，C1、C2 各一次）

> 机制已冒烟验证（2026-08-02）：裸 `--loop` 被时间戳高水位门全量拒收不可行；
> 重打戳拼接 bag 零拒收；每周期边界位姿跳变触发地图 epoch 重置属产品正确行为。
> 证据：`/tmp/loop-smoke-{a,b}-20260802/`（容器内）。

- [x] 重打戳拼接工具转正为 `scripts/restamp-concat-bag.py`，
      加 `--trim-s` 裁掉每段 ~42 s 空闲尾（周期 62 s → ~26 s）。
      注意：只改 header 戳与 TF 戳；session 身份与 `freshness_ns` 不改；
      源 bag 的 QoS 元数据必须原样携带（`/tf_static` transient_local）。
- [x] `profile-graph.sh` `replay-loop` 模式改为播放拼接 bag（单次播放，
      非 `--loop`）。
- [x] **C1 先做 5 min 冒烟**：确认 C1 无类似拒收路径；有则修拼接工具，
      不改产品。**实际由更强证据替代**：`c1-asan-x2`（2 份拼接、ASan 构建）
      输出 390 = 2×195 精确等价，已证明 C1 完整接受拼接回放。
- [x] C2、C1 各跑 30–60 min（~70–140 周期），采 PSS/RSS 时间线。
- [x] **泄漏判据（双重）**：
      - 各周期基线谷值序列的线性斜率 ≈ 0（阈值 1024 KiB/min）
      - 周期"建图↗ → 重置回落"形态完好；回落缺口即单周期泄漏量
- [x] 周期等价门：每周期提交数 ≈ 单圈基准 ±5（恢复稳定门边界损耗，
      实测 1–4 帧）→ **阻塞门**、**AC4**。
- [x] 报告**灵敏度下限**（本次窗口实际可分辨的最小斜率）。
- [x] **升级路径（条件触发）**：斜率 > 0 时加跑一次 Heaptrack 定位分配栈，
      降频按 `工具开销 ÷ 剩余余量` 公式计算。
